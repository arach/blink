# arach Homebrew tap

Homebrew packages maintained by [Arach](https://github.com/arach).

## Blink

Install the Blink command-line interface:

```sh
brew install arach/tap/blink
```

Install the Blink macOS app:

```sh
brew install --cask arach/tap/blink
```

Blink currently requires Apple Silicon and macOS Sonoma or newer.
